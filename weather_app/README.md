# Weather-App
Skyline is a responsive weather app that provides real-time weather information for cities around the world

Users can search for a city and view its current temperature, weather condition, humidity, wind speed, and feels-like temperature.

##  Features

-  Search weather by city
-  View current temperature in Celsius/Fahrenheit
-  Display current weather conditions and icons
-  View humidity levels
-  View wind speed
-  View feels-like temperature
-  Use your location to get local weather
-  Quick access to popular cities
-  Save favorite cities
-  Loading and error states
-  Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Async/Await
- Fetch API
- DOM Manipulation
- Local Storage

## 🌐 API

Skyline uses the **OpenWeatherMap API** to retrieve real-time weather data.

The application uses asynchronous JavaScript with `fetch()`, `async/await`, and `try...catch` to request and handle weather data.
